# Appstore submission package

Assets and metadata to publish open-pebble-ai to the Rebble appstore.

## Contents

```
appstore/
  description.txt          # Long description shown on the app's listing page
  release-notes.txt        # Notes attached to the release
  banner.png               # 720x320 marketing banner (mandatory for apps)
  icons/
    icon-small.png         # 48x48 PNG, listing-page small icon
    icon-large.png         # 144x144 PNG, listing-page hero icon
  screenshots/
    emery_idle.png         # 200x228 PNG, idle screen
    emery_chat.png         # 200x228 PNG, chat-bubble exchange
  publish.sh               # Wrapper around `pebble publish`
  README.md                # This file
```

`banner.png` is regenerated by `scripts/make-banner.py`. Filenames in
`screenshots/` MUST start with the target platform name — `pebble publish`
uses the prefix to route each screenshot, so `emery_idle.png` is treated
as an emery screenshot. The app only targets `emery`, so emery-only is
correct.

## How to publish

The current Rebble submission flow is the web portal at
**dev-portal.rebble.io**. The first submission creates your developer
account. Upload:

- the release `.pbw` (see below),
- `banner.png`, `icons/icon-small.png`, `icons/icon-large.png`,
- the `screenshots/emery_*.png` files,
- the text of `description.txt` and `release-notes.txt`,
- category **Tools & Utilities**, source URL, contact email.

`publish.sh` wraps the older `pebble publish` CLI (which talks to
`appstore-api.repebble.com`). It still works for CLI-based uploads —
run it with no args for a dry-run, `--confirm` to upload — but the web
portal is the primary path and is the only one that takes the banner.

## Building the release .pbw

Run `./scripts/release.sh` from the repo root. It:

1. Clears `src/pkjs/config_defaults.js` — strips the server URL / API key
   that `scripts/dev.sh` bakes in from `.env.local`, so the published app
   ships unconfigured.
2. Builds with `OWUI_DEBUG` off (real dictation, no canned utterances).
3. Refuses to finish if an `sk-...` key is still present in the bundle.

Output: `build/open-pebble-ai.pbw`.

## Refreshing screenshots

Captured from the running emulator:

```bash
pebble screenshot --emulator emery appstore/screenshots/emery_idle.png
# drive the app to the state you want, then:
pebble screenshot --emulator emery appstore/screenshots/emery_chat.png
```

An animated GIF preview is optional. `publish.sh` will upload any
`screenshots/emery_*.gif` if present; capture one with
`pebble screenshot --emulator emery --gif` while driving the app.

## Sanity checklist

- [ ] `./scripts/release.sh` ran clean (clears baked secrets, builds)
- [ ] `package.json` `version` is bumped — `pebble publish` rejects
      re-uploads with the same version
- [ ] `description.txt` reflects the current feature set
- [ ] `release-notes.txt` matches the version being shipped
- [ ] Screenshots show the current UI
- [ ] `banner.png` is present and 720x320
- [ ] `git tag` the release commit for traceability
